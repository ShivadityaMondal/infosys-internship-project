Compario: AI-Powered Price Comparison 🛒Compario is an AI-powered web application that allows users to upload an image of a product and automatically compares prices across various online stores to find the lowest available price. This project was developed as part of the Infosys Springboard Virtual Internship 6.0 to provide consumers with significant cost savings and a time-efficient shopping experience.  Key FeaturesVisual Product Recognition: Users can upload images (JPEG, PNG, JPG), and a fine-tuned Vision Transformer (ViT) model automatically identifies the product without requiring manual text input.  Real-Time Web Scraping: The application automatically fetches live pricing, delivery details, and ratings from major e-commerce platforms, including Amazon, Flipkart, and Snapdeal.  Interactive Comparison Dashboard: Displays a sortable table of products and highlights the best available deals using a user-friendly interface.  User History & Tracking: Utilizes a local database to store user details and securely keep track of recently analyzed products and search history.  Tech StackFrontend & Backend: Built entirely with Python and the Streamlit framework for rapid, data-driven web application development.  AI & Machine Learning: Implements a Vision Transformer model using PyTorch and the Transformers library for high-accuracy image recognition.  Web Scraping: Utilizes BeautifulSoup4, lxml, and Selenium with WebDriver-Manager to extract dynamic content and handle complex HTML layouts across different sites.  Database: Uses SQLite3 for lightweight, serverless, file-based data management.  AuthorShivaditya Mondal
